Here’s a detailed plain-text breakdown of every feature by role (no tables, only bullet points):

---

**Admin Role – Full System Control**

- Can create new users (Admin, Teacher, or Student)
- Can edit any user’s details (name, email, role, status)
- Can delete or permanently remove users
- Can activate or deactivate any user account
- Can assign a student to a specific class/course
- Can create new classes/courses
- Can edit existing classes/courses
- Can delete classes/courses
- Can create new subjects
- Can edit existing subjects
- Can delete subjects
- Can map subjects to specific classes
- Can assign teachers to specific subjects and classes
- Can view all assignments created by any teacher
- Can view all student submissions across the entire system
- Can access system-wide dashboard with overall statistics
- Can manage application-level settings (if any)
- Can see all users, classes, subjects, assignments and submissions in one place
- Has unrestricted access to every part of the system

---

**Teacher Role – Assignment & Grading Management**

- Can create a new assignment
- Can write title for the assignment
- Can write detailed description for the assignment
- Can select which class the assignment belongs to
- Can select which subject the assignment belongs to
- Can set a deadline (date and time)
- Can set maximum marks for the assignment
- Can save the assignment as Draft (not visible to students)
- Can publish the assignment so students can see it
- Can unpublish a published assignment and turn it back to Draft
- Can edit any of their own assignments (title, description, deadline, marks, class, subject)
- Can delete their own assignments
- Can view the list of all assignments they created
- Can filter their assignments by Draft, Published, or Overdue
- Can open any of their assignments and see all student submissions
- Can view individual student answers/submissions
- Can give marks to a student submission (marks cannot be more than maximum marks)
- Can write feedback/comments for a student submission
- Can change the status of a submission (for example: Submitted, Graded, Returned, Late)
- Can see only the classes and subjects assigned to them by Admin
- Cannot create or manage users
- Cannot create or manage classes or subjects
- Cannot see assignments created by other teachers
- Cannot grade submissions of other teachers’ assignments

---

**Student Role – View & Submit Assignments**

- Can view the list of all published assignments assigned to their class
- Can open an assignment and see full details (title, description, deadline, maximum marks)
- Can see the remaining time or whether the deadline has passed
- Can write and submit an answer for an assignment
- Can upload a file as part of the submission (if allowed)
- Can edit or update their own submission only before the deadline
- Cannot edit submission after the deadline has passed
- Can see the current status of their submission (Not Submitted, Submitted, Graded, Late, etc.)
- Can view the marks given by the teacher
- Can view the feedback written by the teacher
- Can see only assignments that belong to their own class
- Cannot see assignments of other classes
- Cannot see other students’ submissions
- Cannot create, edit or delete any assignment
- Cannot give marks or feedback
- Cannot manage users, classes or subjects

---

**Common Features Available to All Roles (after login)**

- Can log in using email and password
- Can log out
- Can see a role-specific dashboard
- Can navigate using role-based menu/sidebar
- Receive clear success or error messages for every action
- See loading indicators while data is being fetched or saved
- Experience a responsive interface that works on mobile and desktop

---
